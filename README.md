# 05 — Dashboard Kualitas Udara
**Materi:** Human-Computer Interaction (HCI) & Data Visualization

## Studi kasus
Dashboard interaktif untuk melihat tren nilai PM2.5 dari data simulasi, dengan filter lokasi dan rentang waktu. Fokus HCI: informasi utama jelas, filter mudah digunakan, dan batasan data disampaikan.

## Menjalankan
```bash
pip install -r requirements.txt
streamlit run app.py
```
Data simulasi tidak menggambarkan kondisi kualitas udara saat ini.
