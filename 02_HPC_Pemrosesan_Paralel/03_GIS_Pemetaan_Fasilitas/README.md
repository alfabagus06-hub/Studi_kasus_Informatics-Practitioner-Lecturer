# Pemetaan dan Visualisasi Lokasi Fasilitas

## Deskripsi Studi Kasus
Proyek ini membahas penggunaan Geographic Information System (GIS) untuk memetakan dan menampilkan lokasi fasilitas berdasarkan informasi geografis. Peta membantu pengguna memahami persebaran lokasi dan memperoleh informasi spasial secara visual.

## Tujuan
- Memahami konsep dasar GIS.
- Menampilkan lokasi fasilitas pada peta.
- Memahami penggunaan koordinat untuk menunjukkan posisi geografis.
- Menyajikan informasi lokasi agar mudah dipahami.

## Teknologi yang Digunakan
- Python
- Streamlit
- Folium
- Streamlit-Folium
- Pandas

## Implementasi
Aplikasi menampilkan peta interaktif berisi beberapa lokasi fasilitas contoh. Pengguna dapat melihat penanda lokasi dan informasi singkat dari setiap fasilitas.

## Cara Menjalankan
pip install -r requirements.txt
streamlit run app.py

## Catatan
Koordinat dan informasi fasilitas dalam proyek ini merupakan data simulasi untuk demonstrasi. Lokasi yang ditampilkan tidak dimaksudkan sebagai data fasilitas nyata yang telah diverifikasi.
